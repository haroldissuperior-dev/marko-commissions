03FAQ

Frequently asked
questions

How do I get something made?

Use the application form below and mention it's a commission, email , or join the Discord. All three reach the same place.

How much does it cost?

Every project is quoted individually once the scope is clear. The price is fixed before work starts, and payment is split 50% upfront / 50% on delivery.

How long will my project take?

It depends on the scope and the current queue, and you'll get an honest estimate before anything starts. If a deadline ever looks like it might slip, you hear about it before it happens.

What if I need changes after delivery?

Design work includes three revision rounds before delivery. Bots get free bug fixes forever, and hosting is on me — only brand-new features are quoted separately.

Do I own the finished work?

Design work is yours outright, layered source files included. For bots, you own the Discord application and everything the bot does — the source code stays with me, since I host and maintain the bot for you free of charge.

What happens after I apply for support?

Your application lands directly in the team's Discord. If it looks like a fit, you'll hear back to talk about the details.
